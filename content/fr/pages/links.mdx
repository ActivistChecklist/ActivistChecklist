  **À retenir :** si tu supprimes tout ce qui suit le ? dans les liens que tu partages, tu évites que les autres membres de tes groupes soient associés à toi et entre elles et eux (c'est un problème, car ça peut réduire l'anonymat dans le militantisme).

## Version courte

**La situation avec le partage de liens :** les grandes plateformes sociales (YouTube, Instagram, etc.) ajoutent maintenant un ***code unique*** chaque fois qu'une personne clique sur « copier le lien » sur une publication.

**Contexte :**

* Toutes les personnes qui cliquent dessus seront reliées entre elles comme un groupe associé sur ce site.
* Si tu partages le lien dans un groupe militant (surtout sur Signal) où certaines personnes risquent d'être ciblées pour leur activité politique, le site (Instagram, etc.) saura alors qui interagit avec qui.  Ça peut lever l'anonymat de personnes qui essaient de protéger leur travail militant.
* Ces entreprises finiront par avoir une copie de la liste des membres de ton groupe.
* Ces entreprises veulent ces infos pour nous vendre de la pub, mais le gouvernement peut forcer une entreprise à lui remettre les données et s'en servir pour cibler les personnes qui résistent.

**Bonne pratique pour ta communauté :** supprime tout ce qui suit le « ? » avant de partager un lien, peu importe où tu le partages.

**Bonne pratique pour te protéger :** fais aussi attention aux « ? » dans les liens partagés par les autres. Ne clique PAS sur ce lien !! Fais un appui long sur ton téléphone et copie le lien. Colle-le dans ton navigateur. Supprime le truc de pistage après le point d'interrogation. ENSUITE, tu peux cliquer dessus.

## Ce que tu peux faire

<Alert type="success">
  **Automatise-le :** tu peux configurer ton navigateur pour qu'il supprime automatiquement tous les liens de pistage si tu utilises [Brave](https://brave.com/) ou le plugin uBlock Origin. Il te suffit d'activer une liste de blocage appelée « **AdGuard/uBO - URL Tracking Protection.** » Dans Brave, tu peux le faire en allant dans <MenuPath inline>**Paramètres** > **Shields** > **Filtres de contenu** > **Filtres**</MenuPath>. [En savoir plus](https://shreyasminocha.me/blog/removing-tracking-query-params)
</Alert>

<HowTo title="Comment supprimer le code de pistage unique">
  **Pour supprimer le code de pistage AVANT de publier :**

  1. Copie le lien depuis une appli de réseau social
  2. Colle-le dans l'appli de messagerie (Signal, etc.)
  3. Supprime tout ce qui suit le « ? »
  4. Appuie sur **Envoyer**

  **Si tu veux supprimer un code de pistage APRÈS l'avoir déjà publié :**

  1. Dans Signal/WhatsApp/iMessage, fais un appui long sur un message jusqu'à ce qu'un menu apparaisse.
  2. Clique sur **Modifier**
  3. Supprime tout ce qui suit le « ? »
  4. Appuie sur **Enregistrer**
</HowTo>

**Autres astuces :**

* Si tu utilises le navigateur Brave ou Firefox, tu peux faire un clic droit et sélectionner « Copier le lien sans pistage… », ce qui supprimera automatiquement ces codes de pistage.

## Questions fréquentes

**Est-ce que ça veut dire que Signal n'est pas sûr ?**

Signal est ce qu'il y a de plus sûr quand on utilise un téléphone. Ce pistage ne se passe pas dans Signal. Il se passe sur les plateformes des géants de la tech, parce qu'elles ont trouvé un autre moyen de nous pister pour nous vendre de la pub.

**Et les codes de pistage du type ?utm_source= ?**

Ils sont moins importants. Ils ne te pistent pas de façon unique et ne nous associent pas entre nous.

**J'ai supprimé la partie avec le code de pistage et maintenant le lien ne marche plus. Qu'est-ce que je dois faire ?**

Sur certains sites, ce qui suit le ? est nécessaire pour que le lien fonctionne, ce qui peut rendre tout ça un peu déroutant. Si tu ne sais pas trop comment partager le lien en sécurité, essaie de trouver un contenu similaire sur un autre site qui n'a pas de code de pistage.
