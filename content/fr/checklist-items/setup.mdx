<HowTo title="Comment configurer le téléphone">
  1. Rétablis la configuration d'usine de l'appareil s'il a déjà servi. Instructions : [iPhone](https://support.apple.com/en-us/108931) / [Android](https://support.google.com/android/answer/6088915?hl=en)
  2. Ignore ou refuse toutes les étapes de configuration facultatives (téléphone, suivi de localisation, analyses/suivi, sauvegarde dans le cloud, etc.)
  3. **Important :** Ne te connecte PAS avec ton compte Apple / Google habituel pendant la configuration initiale (ni à aucun autre moment). On te le demandera, mais cherche bien le bouton « Ignorer ». Idéalement, active le téléphone AVANT de créer le compte Apple/Google, car ces comptes demandent généralement un numéro de téléphone et tu veux utiliser ton nouveau numéro.
</HowTo>
