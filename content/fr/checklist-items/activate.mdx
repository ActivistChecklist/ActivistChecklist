Voici comment activer le service téléphonique

<HowTo title="Comment activer le téléphone">
  1. Si tu as acheté un téléphone d'occasion, insère la carte SIM dans le téléphone.
  2. **Activer :** suis les instructions sur la carte du forfait prépayé pour l'activer. En général, il faudra :
     * Choisir « Je veux un nouveau numéro » (plutôt que de transférer un numéro existant)
     * Leur indiquer un code postal qui leur servira à te trouver un numéro de téléphone. Tu peux mettre n'importe quel code postal, il n'a pas besoin d'être près de chez toi. Pense à noter le numéro, au cas où.
     * Le code PIN de ton forfait. Tu devras gratter la carte pour le faire apparaître.
     * Le numéro IMEI de ton téléphone. Tu peux le trouver dans les paramètres système.
  3. **Créer un compte :** pour l'activation, tu devras généralement créer un compte auprès de l'opérateur mobile. Quand on te demande une adresse e-mail, utilise la nouvelle adresse que tu as créée, distincte de ton compte principal.
     * **N'utilise pas ton vrai nom** pour créer le compte.
     * **Ne leur donne pas de carte de crédit**. Ça lierait très étroitement ton identité au compte. Il y a presque toujours une option pour sauter cette étape—c'est un téléphone prépayé, après tout !
  4. **Redémarrer ton téléphone :** une fois les étapes d'activation terminées, tu devras peut-être redémarrer le téléphone pour qu'il capte le réseau.
</HowTo>
