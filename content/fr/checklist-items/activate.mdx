---
title: Activer le téléphone
---

Voici comment activer le service téléphonique.

<HowTo title="Comment activer le téléphone">
  <StepList>
   1. Si tu as un téléphone d'occasion, mets la carte SIM dans le téléphone.
   2. **Activer :** Suis les instructions sur la carte du forfait prépayé pour l'activer. En général, il faudra :
      * Sélectionner « I want a new number » (plutôt que de transférer un numéro existant)
      * Leur donner un code postal qu'ils peuvent utiliser pour te trouver un numéro de téléphone. Tu peux mettre n'importe quel code postal, pas forcément près de chez toi. Pense à le noter, au cas où.
      * Le code PIN de ton forfait. Tu devras gratter la carte pour le faire apparaître.
      * Le numéro IMEI de ton téléphone. Tu peux le trouver dans les réglages du système.
   3. **Créer un compte :** Pendant l'activation, tu devras généralement créer un compte auprès de l'opérateur. Quand on te demande une adresse e-mail, utilise la nouvelle adresse que tu as créée, distincte de ton compte principal.
      * **N'utilise pas ton vrai nom** pour créer le compte.
      * **Ne leur donne pas de carte bancaire**. Ça relierait très étroitement ton identité au compte. Il y a presque toujours une option pour sauter cette étape — c'est un téléphone prépayé, après tout !
   4. **Redémarrer ton téléphone :** Une fois les étapes d'activation terminées, tu devras peut-être redémarrer le téléphone pour qu'il capte le réseau.
  </StepList>
</HowTo>
