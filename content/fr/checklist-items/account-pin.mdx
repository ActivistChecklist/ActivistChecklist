Tes comptes bancaires et ton compte chez ton opérateur mobile sont des cibles de grande valeur : mieux vaut y ajouter des protections supplémentaires. Certains de ces organismes se contentent de vérifier ton identité avec ton numéro de téléphone, ton adresse et/ou ta date de naissance. Ce sont toutes des informations que n'importe qui pourrait trouver sur toi en ligne.

Ajouter un code PIN ou d'autres mesures de sécurité permet de t'assurer que tu es la seule personne à y avoir accès.

<HowTo title="Comment ajouter un code PIN à tes comptes sensibles">
  **Voici quelques-uns des comptes que tu voudras sécuriser.**

  1. Comptes bancaires, de carte de crédit, de prêt, de prêt immobilier et d'investissement
  2. Ton opérateur mobile (Verizon, T-Mobile, AT&T, etc.)
  3. Fournisseur d'accès à Internet
  4. Fournisseurs d'électricité, de gaz et d'eau
  5. Assurances (santé, habitation, auto, etc.)

  **Comment ajouter un code PIN à chaque compte :**

  1. Appelle leur service client.
  2. Demande si tu peux ajouter un code PIN de vérification.
  3. Génère un [code PIN aléatoire](https://strongphrase.net/passcode) pour chaque compte.
  4. Enregistre-le dans ton [gestionnaire de mots de passe](/essentials/).
  5. Si tu ne peux pas ajouter de code PIN, demande quelles autres fonctionnalités de sécurité ils proposent pour empêcher quelqu'un de se faire passer pour toi et d'accéder à ton compte.
</HowTo>
