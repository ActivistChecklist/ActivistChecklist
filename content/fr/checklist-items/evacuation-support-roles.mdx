<HowTo title="Comment attribuer les rôles">
  Sache exactement qui contacter pour chaque type d'aide pendant l'évacuation.

  1. Identifie une personne pour le soutien émotionnel
  2. Identifie une personne pour l'aide logistique
  3. Identifie une personne pour t'aider à prendre des décisions
  4. Identifie une personne qui peut accéder à ton logement si besoin

  Vous pouvez ajouter ces informations à votre document Fiche de planification de sécurité.
</HowTo>
