Si tu as le temps, utiliser un gestionnaire de mots de passe est la meilleure option, parce qu’il t’aide automatiquement à générer des mots de passe forts, aléatoires et uniques pour chaque site/appli/compte.&#x20;

Si tu dois choisir entre des mots de passe forts (longs, aléatoires) et des mots de passe uniques (pas le même mot de passe réutilisé sur plusieurs sites), mieux vaut choisir des mots de passe uniques. Comme ça, si ton mot de passe est volé sur un site, tous tes autres sites ne seront pas touchés.

Les outils qu’on recommande :

* **1Password** : très facile à utiliser. Un peu plus sécurisé. Coûte 3 $/mois.
* **Bitwarden** : gratuit. Quand même assez sécurisé.

<HowTo title="Comment configurer 1Password">
  <StepList>
    1. **Download:** [Download and install 1Password](https://support.1password.com/get-the-apps/) ($3/month)
    2. **Master password:** Create a strong, random "master password" using a [passphrase generator](https://strongphrase.net/). It should be memorable, but not a password you use anywhere else. Write your master password down on paper rather than storing it digitally. Set a reminder to destroy the paper in a few weeks once you have it memorized.
    3. **Import:** [Import your existing passwords](https://support.1password.com/import/) from your computer or browser
    4. **Apps:** [Install the browser extension](https://1password.com/downloads/browser-extension/) and mobile app ([iPhone](https://1password.com/downloads/ios), [Android](https://1password.com/downloads/android)) to help you save and autofill passwords
    5. **Change passwords:** If you had been re-using similar passwords, update your most important ones using the random password generator built-in to 1Password.
  </StepList>

  Consulte le [guide de démarrage](https://support.1password.com/explore/get-started/) de 1Password pour voir une vidéo de ces étapes.
</HowTo>

Bonus : voici une bonne introduction pour [tirer le meilleur parti de 1Password](https://www.nytimes.com/wirecutter/guides/how-to-use-1password/).
