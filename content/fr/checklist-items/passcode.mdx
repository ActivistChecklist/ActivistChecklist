<HowTo title="Comment changer ton code">
  1. **Select a random passcode that is 8 to 10 digits long.** The most secure way to generate a random passcode is to use your password manager's random password generator feature (set it to numbers only), but you can also use our passcode generator below. (Humans are bad at making up random passcodes, so we suggest not trying to think of one yourself.)

     <PasscodeGenerator />
  2. Change ton code :

     <MenuPath>*iPhone :* **Réglages** > **Face ID et code** > **Modifier le code** > **Options de code** > **Code numérique personnalisé**</MenuPath>

     <MenuPath>*Android :* **Paramètres** > **Sécurité** > **Verrouillage de l'écran** > Saisis ton verrouillage actuel > **Code PIN/Mot de passe** > Saisis un code</MenuPath>
  3. **Entraîne-toi à taper ton nouveau code** au moins 10 fois de suite, dès maintenant, pour avoir plus de chances de t'en souvenir. (Disabling face/fingerprint unlock will force you to enter the passcode every time you open your phone.)
  4. Écris ton nouveau code sur papier et garde-le en lieu sûr chez toi jusqu'à ce que tu l'aies mémorisé. Ensuite, détruis le papier au bout de 2 à 3 semaines. Programmer un rappel sur ton téléphone peut t'aider.
</HowTo>

**Combien de temps faut-il pour craquer un code ?**

| Type de code                              | Temps nécessaire pour le craquer (en moyenne) | Exemple                                                              |
| ----------------------------------------- | --------------------------------------------- | -------------------------------------------------------------------- |
| Motif à 6 chiffres ***facile à deviner*** | **Moins de 24 heures** pour le craquer        | *333666 (common pattern)* or *110582 (date pattern for Nov 5, 1982)* |
| Code ***aléatoire*** à 6 chiffres         | **200 jours** pour le craquer                 | *238253*                                                             |
| Code ***aléatoire*** à 8 chiffres         | **Plus de 40 ans** pour le craquer            | *34780026*                                                           |

*Remarque* : ces durées ne s'appliquent qu'aux téléphones. Les ordinateurs se craquent beaucoup plus vite et ont besoin de mots de passe bien plus robustes.

*Sources :* les estimations du tableau ci-dessus se basent sur le nombre de tentatives par seconde réellement observé avec les outils de piratage forensique utilisés par les flics. Si tu as besoin de plus de sécurité, utilise un code à 10 chiffres : il te protégera même dans les pires scénarios de craquage possibles. Consulte les sources indiquées dans la [FAQ sur les codes ici](https://strongphrase.net/passcode).
