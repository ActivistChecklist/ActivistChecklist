Les flics peuvent accéder aux vidéos sur ton téléphone soit en le confisquant et en le piratant, soit en obtenant un mandat de perquisition pour ton app de photos dans le cloud (si tu en utilises une).

L'app Tella te permet de stocker des vidéos, des photos et des fichiers de façon plus sécurisée sur ton téléphone. Elle ajoute une couche de chiffrement supplémentaire qui rend la tâche plus difficile aux flics pour y accéder. Si tu prends les vidéos/photos depuis l'app, elles ne seront jamais enregistrées dans ta pellicule, ce qui évite qu'elles soient envoyées dans le cloud.

<HowTo title="Comment utiliser l'app Tella pour filmer">
  1. **Installe** l'[app Tella](https://tella-app.org/)
  2. **Configure un code d'accès** <u>**différent de celui de ton téléphone**</u>**.** Utilise un [générateur de code d'accès aléatoire](https://strongphrase.net) pour ça. Enregistre le code d'accès dans ton gestionnaire de mots de passe.
  3. **Filme depuis Tella :** l'option la plus sûre, c'est de lancer l'enregistrement de ta vidéo depuis Tella plutôt que depuis l'app appareil photo habituelle. Comme ça, elle n'est jamais enregistrée dans ta pellicule habituelle.

  **Et la synchronisation cloud dans Tella ?** Tu peux choisir d'activer les options de synchronisation cloud si tu as vraiment besoin de sortir les données de ton téléphone le plus vite possible. Mais garde en tête que les flics peuvent obliger les entreprises tech à leur remettre ces informations.
</HowTo>
