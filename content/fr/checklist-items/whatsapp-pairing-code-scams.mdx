**C'est quoi, « Appareils connectés » ?** WhatsApp te permet d'utiliser ton compte sur d'autres appareils (un ordinateur, une tablette, un deuxième téléphone) en les connectant avec un code QR ou un code d'association. La plupart des gens n'utilisent jamais cette fonctionnalité. Consulte l'[explication officielle](https://faq.whatsapp.com/1324084875126592/?cms_platform=web) de WhatsApp si tu veux en savoir plus.

Des personnes malveillantes ont compris qu'elles pouvaient te piéger pour que tu connectes *leur* appareil à ton compte. Si un site web ou une personne inconnue te guide pour une « vérification » qui consiste à saisir un code dans WhatsApp, ce n'est pas une vérification. Concrètement, c'est toi qui leur donnes un accès complet à tes discussions. La même arnaque fonctionne avec les codes QR.

Donc : **ne saisis jamais de code d'association et ne scanne jamais de code QR WhatsApp parce qu'un site web ou une personne te l'a demandé.** Scanne un code QR WhatsApp uniquement quand c'est **toi-même** qui viens d'ouvrir WhatsApp Web ou Desktop.

Tu peux vérifier ton compte à tout moment. Consulte [Vérifie régulièrement les appareils connectés](/whatsapp/#whatsapp-linked-devices).
