テック企業（Googleなど）は、アクティビストの[アカウントデータをすべて](https://cldc.org/google-is-a-fcking-snitch/)引き渡すよう求める[政府からの要求](https://theintercept.com/2025/09/16/google-facebook-subpoena-ice-students-gaza/)をよく受けています。こうした要求には「緘口令」が付いていることが多く、その場合、企業は数か月から数年後までユーザーに知らせることができません。

[Proton Mail](https://proton.me/mail)、[Drive](https://proton.me/drive/)、[Docs](https://proton.me/drive/docs)、[Sheets](https://proton.me/drive/sheets)のような[暗号化された](term:encryption)クラウドツールなら、運営会社があなたのデータを読める形で持っていないので、引き渡しを求められても渡せるものがありません。政府がデータを手に入れたいなら、あなた本人に直接要求しなければなりません。つまり、あなたは事前に通知を受け、法的サポートを受けながら異議を申し立てるチャンスを得られます。

<Alert type="warning">
  **暗号化メールの限界：** Protonはサーバー上のすべてのデータを暗号化しています。でも、暗号化によって送り手と受け手の両方が守られるのは、受信者も暗号化メールを使っている場合だけです。 Gmailユーザーにメールを送れば、Googleの手元にコピーが残り、それを引き渡される可能性があります。

  \*\*機密性の高いやり取りには、必ずSignalを使いましょう。\*\*消えるメッセージもオンにしておくこと。
</Alert>

<HowTo title="Proton DocsとProton Mailの設定と使い方">
  **Protonアカウントを作成する**

  <StepList>
    1. [無料のProtonアカウント](https://account.proton.me/signup)に**登録する**。
       <Alert type="info">
                 **おすすめ：** [ランダムなユーザー名](https://strongphrase.net/username)と[ランダムな表示名](https://strongphrase.net/identity)を選んでおきましょう。そうすれば、このメールアドレスを共有していることを明かさずにすみます。
       </Alert>
    2. **Verify:** When asked to verify if you are a human, choose the “CAPTCHA” option rather than the “email” option, so you don't link your true identity.
    3. When asked to set your phone number / email as a recovery method, choose **Maybe later.**
  </StepList>

  **Use Proton Drive/Docs/Sheets**

  * **Create and edit** documents collaboratively much like Google Docs. Someone must have a Proton account to be shared directly.
  * **Share securely:** Only use "share by link" when necessary, set a document password, set the "public link" to have an expiration date.

  **Use Proton Mail**

  * **Use Proton Mail for:** website accounts, newsletters, public-facing communications needing anonymity, and non-sensitive organizing work.
  * **Don't use any email for:** truly sensitive communications that might put someone at legal risk.
  * **What gets encrypted vs not:** Messages between Proton Mail users are automatically end-to-end encrypted. Messages to people using a different email provider will not be encrypted, but you can send a [password-protected email](https://proton.me/support/password-protected-emails).
</HowTo>

[CryptPad](https://cryptpad.fr/)も暗号化ドキュメントの選択肢として人気ですが、使いこなすのはかなり大変です。必要な機能がそろっていれば、同じ結果が得られます。

<Alert type="info">
  **Protonを安全に使うために:** ProtonはGmailやGoogle ドキュメントと比べて大きな改善ですが、知っておくべき実際の限界もあります。何が暗号化され、何がされないのか、そしてよくある落とし穴を避ける方法については、[Protonを安全に使うためのガイド](/proton/)をチェックしてください。
</Alert>
