Las empresas de tecnología (como Google) a menudo reciben [solicitudes del gobierno](https://theintercept.com/2025/09/16/google-facebook-subpoena-ice-students-gaza/) para entregar [todos los datos de la cuenta](https://cldc.org/google-is-a-fcking-snitch/) de una persona activista. Esto suele incluir una "orden de silencio", lo que significa que la empresa no puede avisarle a la persona usuaria hasta meses o años después.

Las herramientas en la nube [cifradas](term:encryption) como [Proton Mail](https://proton.me/mail), [Drive](https://proton.me/drive/), [Docs](https://proton.me/drive/docs) y [Sheets](https://proton.me/drive/sheets) hacen que la empresa no tenga copias legibles de tus datos que pueda entregar. Si el gobierno los quiere, tendría que pedírtelos a ti, dándote aviso y la oportunidad de impugnarlo con apoyo legal.

<Alert type="warning">
  **Límites del correo cifrado:** Proton cifra todo en sus servidores. Pero el cifrado solo protege ambos extremos si quien recibe también usa correo cifrado. Si le envías un correo a alguien que usa Gmail, Google tiene una copia que puede entregar.

  **Para comunicación sensible, siempre usa Signal** con los mensajes que desaparecen activados.
</Alert>

<HowTo title="Cómo configurar y usar Proton Docs y Proton Mail">
  **Crea una cuenta de Proton**

  <StepList>
    1. **Regístrate** para obtener una [cuenta gratuita de Proton](https://account.proton.me/signup).
       <Alert type="info">
                 **Sugerencia:** Elige un [nombre de usuario aleatorio](https://strongphrase.net/username) y un [nombre visible aleatorio](https://strongphrase.net/identity) para que tengas la opción de no revelar que compartes esta dirección de correo.
       </Alert>
    2. **Verify:** When asked to verify if you are a human, choose the “CAPTCHA” option rather than the “email” option, so you don't link your true identity.
    3. When asked to set your phone number / email as a recovery method, choose **Maybe later.**
  </StepList>

  **Use Proton Drive/Docs/Sheets**

  * **Create and edit** documents collaboratively much like Google Docs. Someone must have a Proton account to be shared directly.
  * **Share securely:** Only use "share by link" when necessary, set a document password, set the "public link" to have an expiration date.

  **Use Proton Mail**

  * **Use Proton Mail for:** website accounts, newsletters, public-facing communications needing anonymity, and non-sensitive organizing work.
  * **Don't use any email for:** truly sensitive communications that might put someone at legal risk.
  * **What gets encrypted vs not:** Messages between Proton Mail users are automatically end-to-end encrypted. Messages to people using a different email provider will not be encrypted, but you can send a [password-protected email](https://proton.me/support/password-protected-emails).
</HowTo>

[CryptPad](https://cryptpad.fr/) es otra opción popular de documentos cifrados, pero es muy difícil de usar. Si tiene las funciones que necesitas, logra el mismo resultado.

</Alert>
