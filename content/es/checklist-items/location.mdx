<HowTo title="Cómo revisar los permisos de ubicación en iPhone">
  <StepList>
    1. Go to <MenuPath inline>**Settings** > **Privacy & Security** > **Location Services**</MenuPath>
    2. Review each app and set to one of these options:
       * **Never: Best choice for most apps**
       * Ask Next Time Or When I Share: Good for apps you rarely need location for
       * While Using the App: Only for essential navigation apps
       * Always: Almost no app should have this permission
    3. Make sure to set the **Camera** app to “**Never**” so you don’t risk revealing your location when you share or upload photos.
    4. Go to the app labeled <MenuPath inline>**System Services** > **Disable Significant Locations**</MenuPath>
  </StepList>
</HowTo>

<HowTo title="Cómo revisar los permisos de ubicación en Android">
  <StepList>
    1. Go to <MenuPath inline>**Settings** > **Privacy** > **Permission manager** > **Location**</MenuPath>
    2. Review each app and set to one of these options:
       * **Don't allow: Best choice for most apps**
       * Ask every time: Good for apps you rarely need location for
       * Allow only while using the app: Only for essential navigation apps
       * Allow all the time: Almost no app should have this permission
  </StepList>
</HowTo>

<Alert type="warning">
  Es muy importante desactivar el rastreo de ubicación en tu app de cámara o de fotos.
</Alert>

**Estas apps tal vez sí necesitan tu ubicación mientras las usas:**

* Navegación (Apple Maps, Magic Earth, CoMaps)
* Apps para pedir transporte (pero solo mientras las usas activamente)

**Algunas apps pueden necesitar permiso temporal:**

* Las apps de entrega de comida solo necesitan tu ubicación cuando estás haciendo un pedido

**Apps que definitivamente NO necesitan acceso a tu ubicación:**

* Apps de fotos
* Apps de redes sociales
* Juegos
* La mayoría de las apps de compras
* Apps de banca
* Apps de noticias
* La mayoría de las apps de productividad

Recuerda: si tienes dudas, desactiva la ubicación y vuelve a activarla solo si de verdad la necesitas.
